# Expense Tracker

A streamlined, terminal-based application for tracking and analyzing capital outflow. This project demonstrates clean code principles, Object-Oriented Programming (OOP), and data-driven visualization.

## Components
- **`data_manager.py`**: The core logic engine handling CSV persistence and data validation via Pandas.
- **`main.py`**: A user-friendly Command Line Interface (CLI) for real-time data entry and auditing.
- **`analysis.ipynb`**: A research-focused Jupyter Notebook for visualizing spending trends and sector allocation.

## Getting Started
1. Install dependencies: `pip install -r requirements.txt`
2. Run the tracker: `python main.py`
3. View analytics: Open `analysis.ipynb` in VS Code or Jupyter.

## Key Features
- **Validation**: Strict date and numeric formatting to ensure dataset reliability.
- **Insights**: Automated statistical summaries (Average, Max, and Total Spend).
- **Visualization**: Interactive Donut charts to identify high-exposure categories.
